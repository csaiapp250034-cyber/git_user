## 💻 How to View & Run Locally

### Option 1: Double Click
Simply open [index.html](file:///d:/portfolio/index.html) in any modern browser (Google Chrome, Microsoft Edge, Firefox, Safari).

### Option 2: Local Python Server
Open terminal in `d:/portfolio` and run:
```bash
python -m http.server 3000
```
Then visit: `http://localhost:3000` in your web browser.

## 🌐 How to Deploy to GitHub Pages (Free Hosting)

1. Create a GitHub repository named `srithara8090-pixel.github.io` (or `portfolio`) under your account `https://github.com/srithara8090-pixel`.
2. Push the files:
   ```bash
   git init
   git add .
   git commit -m "feat: launch premium portfolio website"
   git branch -M main
   git remote add origin https://github.com/srithara8090-pixel/srithara8090-pixel.github.io.git
   git push -u origin main
   ```
3. In GitHub Settings → **Pages**, select branch `main` and root `/`.
4. Your website will be live at `https://srithara8090-pixel.github.io/`!
